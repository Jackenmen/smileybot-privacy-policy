3rd party End User Data statements

The following are statements provided by 3rd-party extensions.

autogist

This cog auto-uploads attachments to gist.github.com uploaded by users as configured by the guild administrators.

banmessage

This cog does not persistently store data or metadata about users.

defender

This cog stores user IDs for the purpose of counting the messages a user sends and/or send the DM notifications the user has subscribed to.

emojiinfo

This cog does not persistently store data or metadata about users.

encoding

This cog does not persistently store data or metadata about users.

fluxerbridge

This cog sends messages sent by users on Discord to Fluxer servers and vice versa. The bot stores a mapping between users and the IDs of their messages on both sides of the bridge.

freshmeat

Freshmeat stores no user data.

githubcards

GitHubCards stores no personal information.

maintenance

This cog stores user's Discord IDs for operational data, in the form of whitelist to specify what users may interact with the cog/bot. This data is only deleted on Discord's user deletion requests.

modroles

This cog does not persistently store data or metadata about users.

nitrorole

This cog does not persistently store data or metadata about users. Discord IDs of users may occasionally be logged to file as part of error logging.

otherbot

This cog does not persistently store end user data. This cog does store discord IDs as needed for operation.

rlstats

This cog stores data provided by users for the purpose of better user experience. It does not store user data which was not provided through a command. Users may remove their own data without making a data removal request. This cog will remove data when a data removal request is made.

roleutils

This cog does not persistently store any data or metadata about users.

rss

This cog does not persistently store data or metadata about users.

rssnotifier

This cog stores Discord user IDs when the user explicitly opts in receiving mentions about feed updates. No personal identifiable data is stored by this cog.

sentryio

This cog does not record end user data.

shell

This cog does not persistently store data or metadata about users.

tools

This cog does not persistently store data or metadata about users.

voicetools

This cog does not persistently store end user data. This cog does store discord IDs as needed for operation. Discord IDs of users may occasionally be logged to file as part of debug logging.
